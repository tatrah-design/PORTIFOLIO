ROBERT'S BEGINNER PORTFOLIO

FILES
-----
index.html = structure and content
style.css  = design and layout
script.js  = JavaScript interaction

HOW TO OPEN
-----------
1. Open this folder in VS Code.
2. Open index.html in a browser.
3. Make changes in VS Code.
4. Save and refresh the browser.

IMPORTANT
---------
The contact form is a front-end demonstration.
It does not actually send an email.

OWNERSHIP QUESTIONS TO PREPARE FOR
----------------------------------
1. HTML creates the structure of the website.
2. CSS controls the appearance and layout.
3. JavaScript adds interaction.
4. Navigation links use section IDs.
5. The media query helps the site work on small screens.
6. new Date().getFullYear() gets the current year.
